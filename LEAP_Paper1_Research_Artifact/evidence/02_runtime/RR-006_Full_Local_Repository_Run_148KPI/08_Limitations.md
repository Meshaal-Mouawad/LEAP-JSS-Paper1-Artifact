# Limitations

- This is a broad local repository stress test, not a curated enterprise KPI benchmark.
- The generated KPI count should not be interpreted as the number of validated business KPIs in a production portfolio.
- Some generated pages may come from evidence-register CSV/MD files, test fixtures, scripts, or generated artifacts. Those should be treated as scan-noise warnings unless a release QA rule classifies them as defects.
- The terminal log does not provide independent human validation of each generated page.
